# S1 - Admin Quản Lý Sự Kiện: Tiến Độ Hiện Tại

## ✅ KẾT LUẬN TỔNG QUÁT

Hệ thống quản lý sự kiện đã có nền tảng backend + frontend khá đầy đủ: CRUD event, ẩn/hiện, banner S3, thể loại event, trang chi tiết public và khóa đăng ký khi hết slot (cả FE lẫn BE).

---

## 📊 TRẠNG THÁI HIỆN TẠI

| Thành phần | Trạng thái | Ghi chú |
|---|---|---|
| Event CRUD + visibility | ✅ | Tạo/sửa/ẩn/hiện, auto `Ended` theo `EndTime` |
| Banner upload S3 | ✅ | Presigned URL → upload trực tiếp S3 → lưu `bannerUrl` |
| Category CRUD (admin) | ✅ | Bảng `EventManagementCategories`, dropdown khi tạo event |
| Event detail (public) | ✅ | `/events/:eventId` hiển thị đầy đủ thông tin + banner |
| Khóa đăng ký hết slot | ✅ | FE disable form + BE atomic `RegisteredCount` |
| Registration API | ✅ | `POST /events/{eventId}/register`, `GET /my-tickets` |
| Deploy & verify | ⏳ | Cần `sam build && sam deploy` |

---

## 🔧 CHỨC NĂNG ĐÃ HOÀN THÀNH

### Backend — EventFunction
- Public: `GET /events`, `GET /events/{eventId}`, `GET /categories`
- Admin: CRUD event, `PATCH /admin/events/{id}/visibility`, `GET /admin/events/banner-upload-url`
- Admin categories: `GET/POST /admin/categories`, `PUT/DELETE /admin/categories/{id}`
- Banner: upload qua S3 presigned URL, bucket `EventManagementEventBannersBucket`
- Event lưu `CategoryId` + `Category` (tên denormalized)

### Backend — RegistrationTicketLambda
- `POST /events/{eventId}/register` (Cognito auth):
  - Kiểm tra event Active, visible, chưa hết hạn
  - Kiểm tra trùng đăng ký
  - Tăng `RegisteredCount` atomic với DynamoDB condition (`RegisteredCount < MaxSlots`)
  - Trả `409 Conflict` nếu hết slot
  - Tạo ticket trong `EventManagementTickets`
- `GET /my-tickets` — danh sách vé của user

### Frontend
- **EventForm**: upload banner S3, chọn category từ dropdown
- **CategoryManagementPage**: admin tạo/kích hoạt/vô hiệu hóa thể loại (`/admin/categories`)
- **EventDetail**: load event thật, hiển thị banner/category/slots, form đăng ký hoặc thông báo khóa
- **EventCard**: luôn có nút "View Details" với event Active (kể cả hết slot)
- **RegistrationForm**: gọi API đăng ký, yêu cầu đăng nhập, hiển thị lỗi hết slot

## 🔍 LOGIC QUAN TRỌNG

### Ẩn / Hiện / Hết hạn
| Thao tác | Hành vi |
|---|---|
| **Ẩn/Hiện** | `IsVisible = false/true` — admin thấy hết, user không thấy event ẩn |
| **Auto Ended** | `EndTime < now` → status hiển thị `Ended`, user không đăng ký được |
| **Hết slot** | `RegisteredCount >= MaxSlots` → FE khóa form, BE từ chối đăng ký (409) |

### Hủy vs Ẩn vs Xóa
- **Ẩn/Hiện**: chỉ đổi `IsVisible`, data còn nguyên
- **Ended**: tự động theo thời gian, không xóa data
- Không còn hard delete — data event được giữ lại

### Banner S3 flow
1. Admin chọn ảnh trong `EventForm`
2. `GET /admin/events/banner-upload-url?contentType=&eventId=`
3. FE `PUT` ảnh lên S3 qua presigned URL
4. Lưu `bannerUrl` stable vào event khi create/update

### Category
- Admin tạo thể loại tại `/admin/categories`
- Khi tạo/sửa event: bắt buộc chọn category active từ dropdown
- Event lưu `CategoryId` + tên category

## 📝 GHI CHÚ KỸ THUẬT

- Biến môi trường EventFunction: `EVENT_TABLE_NAME`, `CATEGORY_TABLE_NAME`, `BANNER_BUCKET_NAME`
- Biến môi trường TicketFunction: `EVENT_TABLE_NAME`, `TICKET_TABLE_NAME`
- Đăng ký yêu cầu JWT Cognito (route protected bởi Globals authorizer)
- Event cũ thiếu `IsVisible` được coi là `true`; thiếu `CategoryId` vẫn chạy nếu có tên category text
